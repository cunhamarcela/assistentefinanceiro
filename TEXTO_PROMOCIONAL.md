## Versão para Imprensa
O Assistente Financeiro é um aplicativo móvel gratuito desenvolvido para ajudar usuários brasileiros a gerenciar suas finanças pessoais de forma inteligente e segura. 

Com recursos de categorização automática, relatórios detalhados e sincronização em nuvem, o app oferece uma solução completa para controle de gastos pessoais. A interface moderna e intuitiva torna o gerenciamento financeiro acessível para usuários de todos os níveis de experiência.

O aplicativo utiliza tecnologias de segurança avançadas, incluindo autenticação via Apple ID e Google, além de criptografia de dados, garantindo a proteção das informações financeiras dos usuários.

Disponível gratuitamente na App Store para dispositivos iOS.
