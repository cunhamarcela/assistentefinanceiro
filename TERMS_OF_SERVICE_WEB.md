## 2. Descrição do Serviço

### 2.1 O que é o Assistente Financeiro
O Assistente Financeiro é um aplicativo móvel gratuito que permite aos usuários:
- Registrar e categorizar gastos pessoais
- Visualizar relatórios financeiros
- Gerenciar categorias de despesas
- Sincronizar dados entre dispositivos
- Personalizar perfil de usuário

### 2.2 Natureza do Serviço
- **Ferramenta de Organização:** O app é uma ferramenta de organização pessoal, não um serviço de consultoria financeira
- **Não Processamos Transações:** Não processamos transações bancárias reais
- **Dados Inseridos pelo Usuário:** Todos os dados financeiros são inseridos manualmente pelo usuário
